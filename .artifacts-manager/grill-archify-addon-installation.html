¿Qué debe ocurrir con el JSON IR cuando se archiva, restaura o elimina el HTML Archify?

Recomendado: archivar/restaurar conjuntamente y eliminar el JSON junto con el HTML por defecto; `--keep-file` debe conservar ambos archivos para recuperación manual.
