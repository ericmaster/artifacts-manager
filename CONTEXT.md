# Artifacts Manager Domain

The `artifacts-manager` domain establishes the canonical terminology for multi-project artifact indexing, interactive visualization, and agent-assisted exploration across all workspaces.

## Language

**Artifact**:
A standalone, self-contained file (`.html` or `.md`) generated by an agent or engineer to explain, visualize, or document a concept, system topology, architecture, refactor, state machine, or data schema.
_Avoid_: snippet, scratchpad, docstring, dump

**Diagram**:
A visual explanation contained within an Artifact. An Artifact may contain one or more Diagrams.
_Avoid_: artifact, figure

**Diagram Composition**:
The arrangement of one or more typed Diagrams within a single Artifact, with each Diagram contributing a distinct view of the concept.
_Avoid_: diagram bundle, standalone diagram set

**Diagram Type**:
A visual grammar used by a Diagram, such as architecture, sequence, state, ER, or timeline. The user may specify the type, or the agent may suggest or select one based on the concept being explained; an explicit user choice wins.
_Avoid_: artifact type, renderer

**Diagram Authoring Guidance**:
Optional agent- and user-facing instructions and tools for selecting Diagram Types and applying their visual and semantic rules within an Artifact. Without an explicit user choice, the agent selects suitable types; interaction or animation is included only when explicitly requested.
_Avoid_: diagram producer, renderer plugin

**Interactive Diagram**:
An HTML Diagram that uses interaction or animation, such as clickable inspection or animated connections, to clarify data flow or contrast architectural changes.
_Avoid_: static diagram, animation-only graphic

**Manifest**:
The per-project catalog file located at `<project-root>/.artifacts-manager/manifest.json` describing all local artifacts, their metadata, descriptions, tags, and timestamps.
_Avoid_: catalog file, index.json, artifact-list, inventory

**Central Registry**:
The global machine configuration file located at `~/.artifacts-manager.json` tracking all registered repository roots on the host.
_Avoid_: global db, projects registry, registry cache

**Artifact Viewer**:
The dedicated web interface component that sandboxes HTML artifacts in responsive iframes or renders styled Markdown with syntax highlighting and diagram support.
_Avoid_: preview frame, renderer window, iframe modal

**Tag**:
A normalized lowercase classification label (e.g. `architecture`, `database`, `refactor`, `topology`) assigned to an artifact to facilitate multi-dimensional filtering across projects.
_Avoid_: category, label-string, keyword-meta

**Interactive Topology**:
An HTML artifact featuring dynamic vector graphics, zoom/pan navigation, clickable nodes, or step sequences that allow interactive inspection of systems.
_Avoid_: static diagram, wireframe screenshot, flowchart image
